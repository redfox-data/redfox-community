# TikTok监控订阅推送 / tiktok-subscribe

---

## 简介

订阅 TikTok 关键词、指定账号与话题，每天 9:00 自动拉取昨日新内容（关键词新爆款视频 / 账号新作品 / 话题新作品），按订阅项分组生成 HTML 日报——一次订阅，每天自动掌握订阅内容的更新动态。

**核心价值**

- 🎯 **三类订阅一次管理**：关键词、账号、话题混合订阅，总上限 100 项，每天 9:00 自动推送
- 📊 **指标齐全**：播放、点赞、评论、分享与发布时间，全部订阅项按播放数降序展示
- 🧭 **无更新自动折叠**：昨日无更新 / 近 7 天无更新订阅项折叠提示，快速聚焦有更新的内容
- 🔗 **链接直达**：作品链接完整可点击，一键跳转核对
- 📈 **AI 语义总结**：归纳今日主题与各订阅项的主题 / 观点，帮助快速理解内容动态

**适用对象**

- 🤝 **品牌方 / MCN** — 盯关键词热度与达人账号动态，评估合作与投放窗口
- 🧑‍💻 **内容运营** — 监控竞品关键词与话题热度变化，捕捉选题灵感
- ✍️ **创作者 / 研究者** — 追踪选题热度与爆款规律，积累内容数据

---

## 功能特性

### 核心功能

- 🔍 **三入口订阅**：关键词（按点赞热度拉取最近一天新视频）、账号（secUserId / 分享链接）、话题（话题 ID）
- ⏰ **每日自动推送**：自动化任务内置全部订阅项，每天 9:00 自动拉取昨日时间窗内新内容
- 🗓️ **时间窗口过滤**：按「昨日 9:00 ~ 今日 9:00」过滤并智能翻页，支持指定历史日期
- 📊 **互动数据齐全**：播放 / 点赞 / 评论 / 分享 / 发布时间，按播放数降序展示
- 📑 **HTML 日报**：TikTok 平台风格，按订阅项分组展示，支持导出 PDF / 高清图片
- 📈 **AI 语义总结**：今日主题总结 + 单订阅项主题 / 观点解读（标注为推测）
- 😴 **无更新折叠**：昨日无更新 / 近 7 天无更新订阅项自动折叠提示

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 重要数据说明

- 每次成功查询可能消耗积分：关键词 / 话题每翻一页消耗 1 次调用（每日模式默认最多 3 页）；账号订阅项 1 次调用返回近期全部作品；HTML 日报与 AI 总结为本地离线生成，不消耗积分
- 每日拉取「昨日 9:00 ~ 今日 9:00」时间窗（本地时区）内作品；接口不支持按时间排序，Skill 内部逐条比对过滤
- 作品均按播放数降序展示；发布时间按本地时区展示
- 账号订阅需要 secUserId（MS4w 开头）或带 `sec_uid=` 参数的分享链接；话题订阅需要话题 ID（ch_id）
- 关键词订阅项仅判定「昨日有无更新」，不做 7 天回溯（避免额外积分消耗）
- AI 语义总结与对话输出一致，均为基于公开数据的 AI 分析，明确标注为推测，仅供参考
