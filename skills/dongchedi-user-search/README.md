# 懂车帝用户搜索和作品订阅 / dongchedi-user-search

---

## 简介

输入关键词就能搜到懂车帝上的用户（作者）账号，粉丝数、简介一眼看清；选中想看的用户，他的作品列表立刻呈现——标题、类型、阅读、点赞、评论、收藏、发布时间清晰展示，默认先看最新 20 条、随时可查看全部，每条作品都能点链接跳转原页；还能订阅感兴趣的用户，每天自动收到 TA 昨日更新的作品。

**核心价值**

- **两步直达**：先按关键词搜用户，选中后立即拉取作品列表，找人和看内容一气呵成
- **数据完整**：用户粉丝数、简介，作品阅读/点赞/评论/收藏/发布时间全部呈现，作品列表默认展示最新 20 条、支持查看全部
- **链接直达**：用户主页与每条作品均附可点击链接，一键跳转查看详情
- **翻页浏览**：候选用户多时可多页翻看，不遗漏任何一个账号
- **订阅追踪**：订阅用户后每天 9:00 自动推送 TA 昨日更新的作品，持续追踪不错过

**适用对象**

- 🔍 **内容创作者** — 找汽车领域对标账号，研究他们的选题方向和内容表现。
- 📊 **运营 / 数据分析** — 摸清某个品牌/车型在懂车帝上有哪些活跃创作者。
- 🏢 **品牌 / MCN** — 筛选汽车领域潜在合作达人，按粉丝量和作品数据评估价值。
- 🚗 **汽车行业从业者** — 追踪喜欢的车评人，快速浏览其近期全部作品。

## 功能特性

### 核心功能

- **用户关键词搜索**：输入品牌名、车型或领域词，搜索懂车帝用户（作者）
- **用户信息展示**：昵称、粉丝数、简介、用户ID、主页链接一次看全
- **作品列表查询**：选中用户即可获取其作品列表，含标题、类型、阅读、点赞、评论、收藏、发布时间；默认展示最新 20 条，回复「查看全部」展开完整列表
- **作品直达**：每条作品附可点击链接，一键跳转查看原作品
- **翻页浏览**：用户列表支持多页翻看
- **订阅推送**：订阅用户后，每天 9:00 自动推送 TA 昨日更新的作品

## 使用指南

直接用自然语言说出你想找的懂车帝用户，或想看谁的作品即可，无需记忆固定命令。

### 常用说法速查

| 意图         | 示例话术                             | 效果                                     |
| ------------ | ------------------------------------ | ---------------------------------------- |
| 搜领域用户   | 「搜一下懂车帝的越野用户」             | 以"越野"查询，展示用户列表                 |
| 找车评作者   | 「懂车帝有哪些车评作者」               | 以"车评"查询，展示用户列表                 |
| 看某用户作品 | 用户列表展示后回复「2」或「小米公司」    | 展示该用户的作品列表（默认最新 20 条）      |
| 查看全部作品 | 作品列表展示后回复「查看全部」          | 续接展示剩余作品，直至全部展示完毕          |
| 翻页查看更多 | 用户列表展示后回复「下一页」            | 自动递增页码翻页，结果连续不重复            |
| 订阅用户更新 | 作品列表展示后回复「订阅」              | 每天 9:00 自动推送该用户昨日更新的作品      |
