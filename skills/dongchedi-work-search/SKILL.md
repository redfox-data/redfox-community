# 懂车帝作品关键词搜索

> 按关键词搜索懂车帝作品，输出标题、作者、播放、点赞、评论、发布时间和完整作品链接。

---

## 触发场景

当用户提出以下需求时使用本 Skill：

- “懂车帝关键词搜索”
- “搜索懂车帝作品/视频/图文”
- “查某个车系在懂车帝的内容”
- “懂车帝上某品牌有什么内容”
- “关键词：尊界 / 小米 / 智界”

如果搜索无结果，只输出“暂无数据”及可能原因，不要主动替换关键词查询其他内容。

---

## 数据说明

### 输出内容

- **作品列表**：以 Markdown 表格输出搜索结果，含序号、标题、作者、作品ID、播放、点赞、评论、发布时间和完整作品链接
- **内容类型**：支持“综合”与“视频”两种内容类型，默认综合
- **作品链接**：使用完整可点击链接直达作品
- **固定提醒**：输出中附带 API Key 获取提醒

### 排序与口径

- 默认按播放数降序输出；用户指定时可改为点赞、评论、时间或数据服务原始顺序
- 发布时间自动转换为本地时间展示；转换失败时原样展示
- 只展示搜索结果返回的字段，不补造正文、封面或详情信息

## 一键安装

### 前置条件

- Python 3.8+（仅使用标准库，无需安装额外依赖）
- 红狐数据 API Key（前往 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) 注册获取）

### 安装步骤

1. 将技能文件夹放入你的 Skills 目录
2. 配置环境变量 `REDFOX_API_KEY`（配置细节详见 `references/core_workflow.md`）
3. 无需安装额外依赖，直接使用

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 关键词搜索 | 「帮我搜一下懂车帝上智界相关作品」 | 按关键词输出作品列表（默认按播放数降序） |
| 指定视频 | 「搜索懂车帝小米SU7视频」 | 只输出视频类型作品 |
| 指定条数 | 「查懂车帝成都车展内容，显示前10条」 | 只展示前 10 条 |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |
| 继续翻页 | 「下一页」 | 输出下一页 20 条 |

## 注意事项

1. **数据真实性**：所有数值均来自数据服务返回，如实展示，严禁估算或编造
2. **查询无果不替换**：空结果时只输出“暂无数据”及可能原因，不主动改查其他关键词或其他作品
3. **积分保护**：每次成功查询可能消耗积分；未经用户明确指定，不主动翻页或批量查询多个关键词
4. **鉴权**：首次使用需配置环境变量 `REDFOX_API_KEY`，API Key 获取与配置详见 `references/core_workflow.md`
5. **链接完整性**：输出中的作品链接保持完整可点击，不使用被终端截断的 URL
