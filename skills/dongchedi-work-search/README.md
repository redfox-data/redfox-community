# 懂车帝作品关键词搜索 / dongchedi-work-search

---

## 简介

输入品牌、车型、车系或任意关键词，一键搜索懂车帝相关作品：标题、作者、播放、点赞、评论、发布时间与作品链接完整呈现，默认按播放数降序排列，快速看清相关作品热度与内容风向。

**核心价值**

- 🔍 **关键词直达**：按品牌、车型、车系等关键词搜索懂车帝作品
- 📊 **指标齐全**：标题、作者、播放、点赞、评论、发布时间一表呈现
- 🔗 **链接直达**：作品链接完整可点击，一键跳转核对原文
- 🎬 **类型可选**：支持“综合”与“视频”两种内容类型
- ↕️ **灵活排序**：默认按播放数降序，可切换点赞、评论、时间排序

**适用对象**

- 🚗 **汽车行业从业者** — 快速检索车型相关作品，掌握内容热度与口碑风向
- 📣 **品牌方 / MCN** — 监测品牌与车系在懂车帝的内容表现
- ✍️ **内容创作者** — 参考热门车系作品，优化选题与内容策略

## 功能特性

### 核心功能

- 🔍 **关键词搜索作品**：按品牌、车型、车系等关键词搜索懂车帝作品
- 🎬 **内容类型筛选**：支持“综合”与“视频”两种类型，默认综合
- 📊 **核心数据展示**：标题、作者、播放、点赞、评论、发布时间以 Markdown 表格呈现
- 🔗 **完整作品链接**：使用完整链接直达作品，方便逐一核对
- 📄 **灵活分页**：默认按播放数降序展示，可按需翻页或指定展示条数

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 关键词搜索 | 「帮我搜一下懂车帝上智界相关作品」 | 按关键词输出作品列表（默认按播放数降序） |
| 指定视频 | 「搜索懂车帝小米SU7视频」 | 只输出视频类型作品 |
| 指定条数 | 「查懂车帝成都车展内容，显示前10条」 | 只展示前 10 条 |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |
| 继续翻页 | 「下一页」 | 输出下一页 20 条 |
