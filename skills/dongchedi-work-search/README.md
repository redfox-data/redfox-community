# 懂车帝作品关键词搜索 / dongchedi-work-search

---

## 简介

输入品牌、车型、车系或任意关键词，一键搜索懂车帝相关作品：标题、作者、播放、点赞、评论、发布时间与作品链接完整呈现，默认按播放数降序排列，快速看清相关作品热度与内容风向。

**核心价值**

- 🔍 **关键词直达**：按品牌、车型、车系等关键词搜索懂车帝作品
- 📊 **指标齐全**：标题、作者、播放、点赞、评论、发布时间一表呈现
- 🔗 **链接直达**：作品链接完整可点击，一键跳转核对原文
- 🎬 **类型可选**：支持“综合”与“视频”两种内容类型
- ↕️ **灵活排序**：默认按播放数降序，可切换点赞、评论、时间排序

**适用对象**

- 🚗 **汽车行业从业者** — 快速检索车型相关作品，掌握内容热度与口碑风向
- 📣 **品牌方 / MCN** — 监测品牌与车系在懂车帝的内容表现
- ✍️ **内容创作者** — 参考热门车系作品，优化选题与内容策略

## 功能特性

### 核心功能

- 🔍 **关键词搜索作品**：按品牌、车型、车系等关键词搜索懂车帝作品
- 🎬 **内容类型筛选**：支持“综合”与“视频”两种类型，默认综合
- 📊 **核心数据展示**：标题、作者、播放、点赞、评论、发布时间以 Markdown 表格呈现

- 📄 **灵活分页**：默认按播放数降序展示，可按需翻页或指定展示条数

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 关键词搜索 | 「帮我搜一下懂车帝上智界相关作品」 | 按关键词输出作品列表（默认按播放数降序） |
| 指定视频 | 「搜索懂车帝小米SU7视频」 | 只输出视频类型作品 |
| 指定条数 | 「查懂车帝成都车展内容，显示前10条」 | 只展示前 10 条 |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |
| 继续翻页 | 「下一页」 | 输出下一页 20 条 |

### 输出示例

查询成功后，作品列表以 Markdown 表格直接在对话中展示（示意）：

> 关键词：`智界` | 内容类型：综合 | 本页条数：10 | 还有下一页：是

| # | 标题 | 作者 | 作品ID | 播放 | 点赞 | 评论 | 发布时间 | 作品链接 |
|---:|---|---|---|---:|---:|---:|---|---|
| 1 | 智界 xxx 试驾体验… | 创作者A / `author_a` | `71xxxxxxxx` | 1,234,567 | 12,345 | 1,234 | 2026-09-01 10:30 | [打开作品](作品链接) |
| 2 | 智界 yyy 深度评测… | 创作者B / `author_b` | `71yyyyyyyy` | 987,654 | 9,876 | 876 | 2026-09-02 14:00 | [打开作品](作品链接) |

### 关键词建议

- 建议关键词不超过 6 个字，2 个字效果最佳（如 `零跑`、`智界`）；过长的组合词容易超时
- 长组合词请拆成短词分次查询：先查品牌或车系（如 `零跑`），再按需查型号（如 `T03`）
- 一次只查询一个关键词；不支持用空格或逗号一次输入多个词（如 `零跑 智界`、`零跑,智界`）

查询失败（超时、网络错误或任务提交失败）时，会按以下顺序自动重试，最多 2 次：

1. 去掉关键词中的空格后重试，如 `零跑 T03` → `零跑T03`
2. 仍失败时缩为一个实体词再试，如 `零跑T03` → `零跑`（优先保留品牌或车系词；纯英文或数字型号如 `T03` 可保留型号）
3. 两次都失败时，说明失败原因并列出已尝试的关键词，不再继续重试

说明：

- 接口正常返回但没有作品时，只提示“暂无数据”，不会改查其他关键词
- 空格或逗号分隔的多个独立关键词不会自动合并或替换，需要选择其中一个后再查
