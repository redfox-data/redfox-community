# TikTok关键词搜用户 / tiktok-keyword-user-search

---

## 简介

基于红狐数据，在 TikTok 上通过昵称或 handle 搜索用户，并查看指定账号关注的账号列表，分析关注对象画像；两个能力可串联使用，先搜账号再查关注，一次对话完成"搜索定位 → 查关注列表"。

**核心价值**

- **关键词定位用户**：按昵称或 handle 在 TikTok 上找到目标账号，查看粉丝、关注、获赞、作品与认证等画像信息。
- **关注列表查询**：查询指定账号关注的账号列表，了解关注对象情况与认证背景。
- **能力串联**：先按关键词定位账号，再查其关注列表，无需手动复制 ID，一个回合完成两项查询。

**适用对象**

- 🔍 **TikTok 内容研究** — 调研账号粉丝量、活跃度与认证背景，辅助选题与对标分析。
- 📊 **达人筛选 / 同行分析** — 按关键词批量定位达人，或通过关注列表分析同赛道运营动作。
- 🧑‍💼 **品牌 / MCN 投放评估** — 评估账号匹配度，关注画像，判断合作潜力。

---

## 功能特性

### 核心功能

- **关键词搜索用户**：通过昵称或 handle 在 TikTok 上搜索账号，输出用户列表（含粉丝、关注、获赞、作品数）。
- **关注列表查询**：通过用户 ID 查询指定账号关注的账号列表，输出关注对象昵称、Handle、粉丝、作品、获赞、地区与认证信息。
- **链式串联查询**：只给昵称或 handle 也能查关注列表——先搜账号定位，确认后再查其关注列表。
- **筛选与排序**：支持按粉丝区间（1K 以下至 100K 以上）与仅认证账号筛选；搜索结果默认按粉丝数降序排列。
- **翻页续查**：搜索与关注列表均支持续查更多结果，由你主动发起。

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图         | 示例话术                                | 效果                                          |
| ------------ | --------------------------------------- | --------------------------------------------- |
| 搜索账号     | 「搜一下 TikTok 上叫南浔的用户」        | 输出候选账号列表（含粉丝、关注、获赞与作品）  |
| 找特定账号   | 「帮我找 solid.guts 这个账号」          | 按 handle 精确定位账号                        |
| 查看关注列表 | 「查一下这个 TikTok 用户关注了谁」      | 输出关注对象列表（含粉丝、作品、获赞、认证）  |
| 链式串联     | 「查 solid.guts 的关注列表」            | 先搜账号定位，再查其关注列表                  |
| 按粉丝筛选   | 「只搜 10 万粉以上的账号」              | 按粉丝区间筛选搜索结果                        |
| 继续翻页     | 「下一页」                              | 续查更多搜索结果或更早的关注记录              |
