# 小红书视频下载 / xiaohongshu-video-downloader

---

## 简介

贴上带 `xsec_token` 参数的小红书视频链接就能拿到无水印下载直链，复制到浏览器或下载工具就能保存，www.xiaohongshu.com 网页链接和 xhslink.com 短链都能认，不会让你折腾半天还下载到带水印的版本。

> ⚠️ **链接必须携带 `xsec_token` 参数**，否则小红书接口会返回链接格式错误。官方示例链接：
> `https://www.xiaohongshu.com/explore/6a3c7aa6000000001003e071?xsec_token=AB-U4vc8DJUJoY9w-ebP_DvuxgiSNYmx8n35V4zvPo__M=&xsec_source=pc_feed`

**核心价值**

- **贴链即得不费劲**：贴上带 `xsec_token` 的视频链接就能拿到视频下载直链，复制到浏览器或下载工具就能保存，不用装插件、不用开会员。
- **视频干净无水印**：返回的都是无水印视频，收藏、二次创作都能直接拿去用。
- **两种链接都能认**：www.xiaohongshu.com 网页链接和 xhslink.com 短链都能识别，手机分享链接、电脑网页链接贴过来都能解析。
- **批量也省事**：多个链接一次贴上，逐个解析最后汇总，不用一条条来回操作。
- **贴错会提醒**：不是小红书链接、或缺少 `xsec_token` 参数，都会直接告诉你并附上官方示例链接，不会白跑一趟。
- **结果一眼看清**：资源类型、时长、下载链接、封面链接、内容描述分开展示，拿到手就知道该复制哪一个。

**适用对象**

- 🎬 **创作者 / 剪辑师** — 快速保存小红书上的视频素材，用于二次创作
- 📚 **内容收藏者** — 把喜欢的小红书视频备份到本地，不怕原笔记被删
- 🔍 **运营 / 研究者** — 下载竞品或热点视频，慢慢分析

## 功能特性

### 核心功能

- **视频解析**：粘贴带 `xsec_token` 参数的小红书视频链接，一键解析出无水印视频下载链接。
- **批量解析**：支持一次粘贴多个链接，逐个解析并汇总结果，不用一个个来。
- **智能校验**：自动识别小红书视频链接并校验 `xsec_token` 参数，不合规链接提示重新输入并附上官方示例。
- **接口错误兜底**：小红书接口返回链接格式错误时，自动附上官方示例链接，引导重新传入。
- **信息完整**：展示资源类型、时长、下载链接、封面链接，内容描述完整逐行展示不截断。
- **双链接支持**：www.xiaohongshu.com 网页链接和 xhslink.com 短链都能识别（均需携带 `xsec_token`）。

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`) 提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。
