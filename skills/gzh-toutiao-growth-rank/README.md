# 公众号头条增长榜 / gzh-toutiao-growth-rank

---

## 简介

公众号头条增长榜是一款公众号涨量雷达工具：按周统计公众号头条阅读增长（本周 vs 上周），固定按头条增长率降序排名，帮助你快速发现本周正在高速涨量的公众号黑马账号。

**核心价值**

- 📈 周度对比：本周头条阅读 vs 上周头条阅读，增长一目了然
- 🐎 黑马发现：按头条增长率降序排名，涨得最快的账号排最前
- 🗂️ 分类筛选：支持 23 个作者类别，可看综合总榜或单一分类榜

**适用对象**

- 🧑‍💻 内容运营 — 快速锁定同赛道涨量黑马，及时跟进对标
- 📣 品牌方 / MCN — 发现高增长账号，辅助投放与合作决策
- ✍️ 公众号创作者 — 学习高增长账号的内容方向与选题

---

## 功能特性

### 核心功能

- 📊 **周度头条增长榜**：按自然周（周一至周日）统计公众号头条阅读增长
- 🏆 **增长率降序排名**：固定按头条增长率降序展示，最快涨量账号优先
- 🗂️ **23 类作者筛选**：支持人文资讯、健康养生、科技数码等 23 个作者类别；不指定时默认综合全部分类总榜
- 📄 **逐页翻看**：每页 20 条，最多 5 页，逐页输出
- 💬 **对话内直接出榜**：榜单以表格形式直接在对话中完整展示

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 查看最新增长榜 | 「看公众号头条增长榜」 | 输出最新一期综合总榜 |
| 指定分类 | 「健康养生头条增长榜」 | 只输出该分类榜单 |
| 指定期数 | 「9 月 7 日那周的榜单」 | 查询指定自然周（自动归一为周一） |
| 查看上期榜单 | 「上期榜单」 | 输出上一期榜单（相对最近一期往前推一周） |
| 翻页 | 「下一页」 | 输出下一页 20 条 |
| 查看分类 | 「有哪些分类」 | 列出全部 23 个作者类别 |

## 重要数据说明

- 榜单按自然周更新，统计周期为周一至周日
- 更新时间：每周一下午 16:30 更新新一期榜单；未到更新时间时最新一期可能暂无数据，将自动展示上一期
- 每页固定 20 条，最多可翻 5 页
