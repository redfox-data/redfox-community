## Step 0：鉴权配置（前置步骤）

- 本技能依赖环境变量 `REDFOX_API_KEY`；未设置时脚本会尝试从 `~/.zshrc`、`~/.bashrc` 等 shell 配置文件中读取

## Step 1：数据来源与榜单口径

### 数据来源

- 唯一数据源：红狐 API `POST https://redfox.hk/story/api/gzh/heima/rankList`
- 认证方式：请求头 `X-API-KEY`（即环境变量 `REDFOX_API_KEY`）
- 来源标识：请求体携带 `source` 字段，值为「公众号头条增长榜-GitHub」

### 榜单口径

- **统计周期**：自然周（周一至周日），`rank_date` 为统计周的周一
- **核心指标**：本周头条阅读数（cur_read）vs 上周头条阅读数（prev_read）
  - `growth_val`：阅读增长量 = 本周 - 上周
  - `growth_pct`：阅读增长百分比，如 `431.97` 表示 431.97%
- **榜单排序（固定）**：一律按 **头条增长率（growth_pct）降序** 输出。接口虽支持其他排序字段，本 skill 榜单展示固定用头条增长率降序，不向用户开放切换
- **榜单口径（分类）**：不传 `--type` 时查询**综合全部分类总榜**（跨全部 23 个作者类别统一排名）；传 `--type` 时只查该分类榜。标题中的分类位：不传显示「综合」，传了显示类别名
- **较上期标签**：与上一期榜单（同分类、同样按头条增长率排序）对比名次，标注每个账号 `上升N名 / 下降N名 / 持平 / 新入榜`；上期榜单前 100 名中未出现即为新入榜；上一期无数据时无法比较
- **榜单存档限制**：接口通常只保留最新一期（2026-09-18 实测：2026-08-17/08-24/08-31 均返回空），相邻两期都有数据时较上期标签才会生效，否则整列显示 `—`
- **翻页**：`--page` 1-5，默认第 1 页；每页固定 20 条，逐页输出

### 作者类别（`--type`，不传则默认为综合全部分类总榜）

共 23 个固定类别，仅限以下（与脚本 `AUTHOR_TYPES` 完全一致，传其他值会报错并给出相似类别提示）：

## Step 2：理解用户意图

| 用户意图 | 执行动作 |
|---|---|
| "看头条增长榜 / 公众号头条增长榜"（或"黑马榜"） | 最新一期综合全部分类总榜（排序固定：头条增长率降序） |
| "XX类 头条增长榜"（如"健康养生头条增长榜"） | 加 `--type` |
| "X月X日那周 / 上期" | 加 `--date`（传周内任意一天，自动归一到周一） |
| "下一页 / 第2页" | 加 `--page N`（1-5） |
| 有哪些分类 | `--list-types` |

用户未指定日期时，脚本自动从最近一个周一往前找最近有数据的期数（最多回退 2 周），输出中会标明实际查询的 `rank_date` 与尝试过的日期。

## Step 3：调用脚本

```bash
python3 ~/.qoder/skills/gzh-toutiao-growth-rank/scripts/heima_rank.py                 # 最新一期
python3 ~/.qoder/skills/gzh-toutiao-growth-rank/scripts/heima_rank.py --type 人文资讯  # 分类筛选
python3 ~/.qoder/skills/gzh-toutiao-growth-rank/scripts/heima_rank.py --date 2026-09-07 # 指定期数
python3 ~/.qoder/skills/gzh-toutiao-growth-rank/scripts/heima_rank.py --page 2        # 翻页
python3 ~/.qoder/skills/gzh-toutiao-growth-rank/scripts/heima_rank.py --list-types    # 列出分类
```

参数可组合，如 `--type 科技数码 --page 2`。排序已在脚本内固定为头条增长率降序（无 `--sort` 参数，不可切换）。

**注意**：每次查询脚本会自动追加获取**上一期**榜单（同分类、固定头条增长率排序）用于计算「较上期」标签，会产生额外 API 调用（最多 5 次/期，找齐本页账号即提前停止）；本期无数据时不会发起上期查询。

## Step 4：渲染榜单

脚本输出 JSON，按下方「输出格式」渲染 Markdown 表格展示。**直接展示脚本返回的数据，不要改写或估算任何数值。**

### 固定规则

**规则 1：榜单必须直接在对话中输出。** 查询到数据后，**必须**以 Markdown 表格形式把当前页榜单完整输出在当前对话中（标题、统计周期、榜单表格、翻页提示缺一不可）。禁止仅用文字概述、禁止省略部分行、禁止改为"已保存到文件"等其他形式代替（`count` 为 0 的空结果除外，按下方空结果处理执行）。

**规则 2：默认每页 20 条，逐页输出。** 每次查询默认只输出当前页 20 条（第 1 页 20 个账号），不主动合并多页、不一次输出全部；用户回复「下一页」时，保持 `--date`、`--type` 不变、仅 `--page` +1 再查一次并输出下一页 20 条；每页固定 20 条。仅当用户明确要求完整榜单（如"输出完整榜单 / TOP100 / 全部账号"）时，才翻完全部 5 页合并一次性输出。

### 榜单模板

```markdown
### 🐎 公众号头条增长榜（2026-09-07 期 · 人文资讯 · 按头条增长率降序）

- 📅 统计周期：2026-09-07 ~ 2026-09-13
- 📄 第 1 / 5 页，本页 20 个账号

| 排名 | 较上期 | 公众号 | 本周头条阅读 | 上周头条阅读 | 头条增长值 | 头条增长率 |
|---|---|---|---|---|---|---|
| 1 | 新入榜 | 丁嘴嘴 | 10w+ | 2 | +10w+ | +5,021,500.00% 🔥 |
| 2 | 下降1名 | 刘备教授 | 42.7w | 3.3w | +39.4w | +1,193.62% 🔥 |
| 3 | 上升12名 | 听雪说影 | 10w+ | 1.5w | +10w+ | +763.50% 🔥 |
| ... |
```

**渲染规则：**

- 标题三要素：期数（rank_date 的日期部分）· 分类（author_type）· 排序方式（sort_label）
- 排名 = `(page-1) × 20 + 序号`，跨页连续编号
- **较上期列**：按 `trend` 字段渲染 —— `up` → `上升N名`（N = trend_diff）；`down` → `下降N名`（N = -trend_diff）；`same` → `持平`；`new` → `新入榜`；`unknown`（上期无数据）→ `—`
- 数值格式化（本周头条阅读 / 上周头条阅读 / 头条增长值）：≥100000（10w）一律显示 `10w+`；10000–99999 用 w 单位保留一位小数（如 `9.8w`）；<10000 原样输出。所有万级数值统一用 `w`，不写"万"
- **头条增长率列显示完整数值，不封顶**：带 `%` 后缀（接口返回 431.97 即 431.97%），超大值可加千分位分隔符（如 `+5,021,500.00%`）提升可读性；≥100% 加 🔥
- 增长值带 `+` 号（≥10w 时为 `+10w+`）
- 若接口返回的 `nickname` 含 Markdown 特殊字符，原样保留

### 翻页提示（每次必须输出）

- `has_next` 为 true（page < 5）：
  > 📄 当前第 **N** 页（共 5 页）。回复「下一页」继续查看。
- `has_next` 为 false：
  > 📄 当前第 **5** 页，已到最后一页。

### 空结果处理（重要）

`count` 为 0 时，只如实告知，**严禁**改查其他分类、其他排序或其他内容顶替：

> 该期榜单暂无数据（查询：2026-09-07 · 人文资讯 · 头条增长率排序）。
> 可能原因：该周该分类无数据，或日期过早/过新。可尝试：换个 `--type` 分类，或指定其他 `--date` 期数。

用户明确指定了 `--date` 时，脚本只查该期，为空就如实报空，不会自动改查别的日期。

## Step 5：注意事项

1. **禁止虚构数据**：所有数值必须来自脚本返回，严禁估算或编造
2. **查询无果不替换**：空结果只说明情况并给出可选调整方向，等用户明确指令后再查（用户未指定日期时的自动回退找期除外，输出需标明实际期数）
3. **日期归一**：`--date` 传统计周内任意一天即可（如 9 月 9 日周三 → 自动归到 9 月 7 日周一）；跨页翻页时要保证 `--date`、`--type` 与上一页一致，只改 `--page`
4. **增长百分比含义**：`growth_pct` 为百分数值（431.97 = 431.97%），非小数，展示时勿除以 100
5. **鉴权**：依赖环境变量 `REDFOX_API_KEY`（未设置时脚本尝试从 ~/.zshrc 等 shell 配置读取），API Key 获取：https://redfox.hk/settings/api-keys?source=github
6. **时效说明**：榜单按周更新，展示时注明统计周期与期数
