# Facebook 主页帖子提取 / facebook-posts

---

## 简介

只需提供一个 Facebook 主页链接，即可批量获取该主页的近期帖子——正文、点赞、评论、图片/视频链接、发布时间与作者信息，并以表格清晰呈现，支持逐页翻看。

**核心价值**

- **一键获取**：粘贴主页链接即可拉取近期帖子，无需逐条翻找、手动记录。
- **数据完整**：正文、互动量（点赞 / 评论）、图片与视频链接、发布时间、帖子链接一应俱全。
- **逐页浏览**：按发布时间倒序排列，支持翻页查看更多帖子，已获取的数据自动去重合并。

**适用对象**

- 🎬 **内容创作者 / 运营人员** — 拆解竞品主页内容策略，沉淀选题与文案灵感。
- 🤝 **MCN / 达人商务** — 合作前快速了解对方作品与内容质量，做背调评估。
- 📊 **品牌方 / 市场调研** — 追踪账号内容表现，开展舆情与竞品分析。
- 📈 **数据分析师** — 批量获取主页帖子数据，做互动与内容规律分析。

---

## 功能特性

### 核心功能

- **主页帖子获取**：输入主页链接即可获取该主页近期帖子，包含正文、点赞、评论等互动数据与帖子链接。
- **链接自动识别**：支持 `facebook.com/用户名` 格式的主页链接，自动识别并提取。
- **分页浏览**：支持翻页查看更多帖子，每页最多 50 条。
- **表格呈现**：对话中以表格摘要展示帖子数据，方便浏览；完整字段与全部媒体链接一并保存留存。

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图         | 示例话术                                             | 效果                             |
| ------------ | ---------------------------------------------------- | -------------------------------- |
| 提取主页帖子 | 「帮我抓取这个 Facebook 主页的帖子：<主页链接>」     | 获取 1 页最近帖子并以表格展示    |
| 翻页看更多   | 「继续，看下一页」                                   | 加载更多帖子，与已有数据去重合并 |

### 输出示例

获取帖子后，你将收到如下表格摘要（示意）：

```
📄 Facebook 主页帖子 · {作者名}
主页：{主页链接} ｜ 数据时间：{获取时间}
本页 {本页条数} 条（累计 {累计条数} 条）｜ 还有更多数据：{是 / 否}

| 序号 | 发布时间         | 文案摘要                     | ❤️ 点赞 | 💬 评论 | 媒体      | 帖子链接     |
|:---:|-----------------|-----------------------------|:------:|:------:|----------|-------------|
| 1   | 2026-10-18 12:07 | 男友說，我們的小豆樹越長越大… | 3,564  | 77     | 🖼️ 图片×1 | [查看帖子]  |
```

## 重要数据说明

- 帖子按发布时间倒序返回，发布时间统一转为北京时间（UTC+8）展示；每页最多 50 条，翻页依赖上一页返回的游标，游标为空表示没有更多数据。
- 图片与视频为临时签名链接，具有时效性（数小时到数天），如需下载请尽快使用，或重新获取以得到新链接。
