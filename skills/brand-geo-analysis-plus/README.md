# 品牌GEO分析Plus版 / brand-geo-analysis-plus

---

## 简介

一个 Skill、三层视角：**全网热榜聚合（hub）+ 近30天社媒深度研究（cn30）+ AI 搜索品牌可见度（geo）**，从「话题热度 - 真实口碑 - AI 回答」三个层位，全面感知中国互联网上的品牌形象。

**核心价值**

- **一站式三层视角**：从热搜榜、社媒讨论到 AI 搜索回答，品牌感知全链路一个工具覆盖，无需多工具切换。
- **真实数据驱动**：7 大平台实时热榜 + 3 大社媒平台近 30 天真实讨论 + 3 大 AI 搜索引擎实测回答。
- **量化可衡量**：GEO 综合得分、提及率、平均排名、情绪分布，品牌在 AI 搜索里的可见度不再是玄学。
- **报告即交付**：终端速览表格 + 交互式 HTML 报告，随手留档、分享。

**适用对象**

- 🏢 **品牌方 / 市场运营** — 摸清品牌在全网的真实声量与口碑，负面反馈早发现。
- 📊 **市场 / 舆情分析师** — 跨平台对比竞品表现，产出可直接引用的结构化报告。
- 📈 **GEO / SEO 从业者** — 量化品牌在 AI 搜索里的可见度，找到明确的优化方向。
- ✍️ **内容运营 / 营销策划** — 追全网热点、挖真实用户讨论，选题灵感不断供。

## 功能特性

### 核心功能

- **全网热榜聚合（hub）**：实时抓取百度、知乎、微博、抖音、B站、快手、头条 7 大平台热搜，自动识别跨平台同一热点事件，输出 TOP10 榜单、跨平台小结与趋势预测，支持昨日 / 本周 / 历史 30 天回溯。
- **社媒深度研究（cn30）**：搜索小红书、抖音、公众号近 30 天真实用户讨论，跨平台对比舆情趋势，输出数据速览、核心发现与可视化 HTML 报告，支持自定义关键词与任意天数（1～30 天）。
- **AI 搜索可见度（geo）**：向豆包、Kimi、DeepSeek 三个 AI 搜索引擎批量提问，量化品牌提及率、推荐排名、情绪倾向、信源引用，自动发现竞品并生成对比矩阵，附交互式 HTML 报告。
- **完整品牌诊断**：三模块组合工作流，从热度、口碑、AI 回答三个层位产出结构化品牌感知诊断报告，含分层行动建议。

### 特色亮点

- **三合一产品形态**：一个 Skill 串起「热榜 → 社媒 → AI 搜索」三层信息源，既可单模块使用，也可组合成全维度诊断。
- **确定性指标公式**：GEO 综合得分由提及率（40%）+ 排名（30%）+ 情绪（30%）加权计算，结果可复现、可跨期对比。
- **脏数据自动剔除**：AI 平台限流 / 故障的回答自动标记并排除统计，不污染提及率与情绪结论。

## 使用指南

直接用自然语言说出你的品牌、话题或分析需求即可，无需记忆固定命令。

### 常用说法速查

| 意图           | 示例话术                                                       | 效果                                         |
| -------------- | -------------------------------------------------------------- | -------------------------------------------- |
| 看全网热点     | 「今天全网在聊什么？哪个热点值得追？」                         | 7 平台热榜 TOP10 + 跨平台小结 + 趋势预测     |
| 研究社媒口碑   | 「近30天大家怎么聊无糖饮料？小红书、抖音、公众号都看看」       | 跨平台真实讨论速览 + 核心发现 + HTML 报告    |
| 查 AI 搜索可见度 | 「分析一下元气森林在豆包、Kimi、DeepSeek 里的表现」           | GEO 得分 + 提及率 / 情绪 / 信源 + 交互式报告 |
| 竞品 AI 对比   | 「对比我们和竞品 A，谁在 AI 搜索里被推荐得更多？」             | 提及率 / 排名 / 情绪的竞品对比矩阵           |
| 完整品牌诊断   | 「帮我做一份 XX 品牌的完整感知报告」                           | 热度 + 口碑 + AI 回答三阶段组合诊断          |

### 输出示例

以 AI 搜索可见度分析为例，完成后你将收到一份交互式 HTML 报告，核心摘要大致如下（示意）：

- **跨平台提及率**：83%（豆包 100% / Kimi 67% / DeepSeek 83%）
- **GEO 综合得分**：72 / 100（优秀），最佳平台为豆包
- **情绪分布**：正面 70% / 中性 30% / 负面 0%
- **品牌平均排名**：2.3（推荐列表中上部）
- **TOP 信源**：zhihu.com、baike.baidu.com……若品牌官网未被引用，即为 GEO 优化的切入点

## 重要数据说明

- **热榜（hub）**：小时级更新，默认返回「前一个完整小时」的数据；支持查询昨日热榜、本周热榜与历史 30 天数据。
- **社媒研究（cn30）**：默认检索近 30 天数据，可自定义 1～30 天任意范围。
- **AI 搜索（geo）**：即时提问、实时分析；AI 回答可能随平台算法变化，结果仅反映分析时点的情况，建议定期复测。
