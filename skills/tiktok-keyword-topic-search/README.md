# tiktok关键词搜话题 / tiktok-keyword-topic-search

---

## 简介

输入关键词，一键搜索 TikTok 相关话题：话题名称、话题 ID、使用次数、浏览量、参与人数完整呈现，默认按使用次数降序排列；输入话题 ID 还能继续查看该话题下的作品列表，快速看清话题热度与作品表现。

**核心价值**

- 🔍 **关键词直达话题**：中文、英文、日文等任意关键词，一键搜索 TikTok 相关话题
- 📊 **指标齐全**：使用次数、浏览量、参与人数等核心指标一表呈现
- 🔗 **链接直达**：作品链接完整可点击，一键跳转核对
- 🔁 **先搜后查闭环**：搜话题 → 拿话题 ID → 查话题作品，一条龙完成
- ↕️ **灵活排序**：话题按使用次数/浏览量排序，作品按播放/点赞/评论/分享排序

**适用对象**

- 🧑‍💻 **TikTok 内容运营** — 追踪话题热度，及时把握内容风向
- 📣 **品牌方 / MCN** — 评估话题价值，发现热点话题与表现亮眼的作品
- ✍️ **创作者** — 参考热门话题与高播放作品，优化选题与内容策略
- 📈 **数据 / 研究人员** — 获取结构化话题与作品数据，支持趋势与选品分析

---

## 功能特性

### 核心功能

- 🔍 **关键词搜话题**：输入任意关键词，搜索 TikTok 相关话题
- 📊 **核心数据展示**：话题名称、话题 ID、使用次数、浏览量、参与人数等以 Markdown 表格呈现
- 🔁 **话题作品查询**：按话题 ID 查询该话题下的作品列表
- ↕️ **多维度排序**：话题默认按使用次数降序，可切换浏览量、参与人数；作品默认按播放数降序，可切换点赞、评论、分享
- 📄 **分页浏览**：附带下一页游标信息，可按需继续查看

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 关键词搜话题 | 「帮我搜一下 TikTok 上 cat 相关的话题」 | 输出关键词相关话题列表（默认按使用次数降序） |
| 查看话题作品 | 「查一下话题 ID 7551 下面的作品」 | 输出该话题作品列表（默认按播放数降序） |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |
| 继续翻页 | 「看下一页」 | 基于上一页游标继续输出下一页 |
| 查看原始数据 | 「输出原始返回」 | 输出原始数据内容 |
