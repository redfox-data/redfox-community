# tiktok关键词搜话题

> 按关键词搜索 TikTok 话题，并可按话题 ID 继续查询话题下的作品列表。

---

## 触发场景

当用户提出以下需求时使用本 Skill：

- "TikTok 关键词搜话题"
- "搜索 TikTok 话题/hashtag"
- "查 cat 相关 TikTok 话题"
- "根据话题 ID 查话题作品"
- "先找 TikTok 话题 ID，再查话题作品"

如果用户直接提供话题 ID 并要求查作品列表，可直接查询话题作品。如果搜索无结果，只输出"暂无数据"及可能原因，不要主动替换关键词查询其他内容。

---

## 数据说明

### 输出内容

- **话题列表**：按关键词输出相关话题，含话题名称、话题 ID、使用次数、浏览量、参与人数、挑战标记等字段
- **作品列表**：按话题 ID 输出该话题下的作品，含作者、作品 ID、播放、点赞、评论、分享、完整作品链接、内容摘要等字段
- **完整链接**：作品链接为完整可点击链接，直达对应页面
- **分页信息**：附带本页条数、是否还有下一页与下一页游标，可按需继续查看
- **主动衔接**：话题列表输出后，主动提示用户是否需要查看某个话题下的作品数据，并列出前几个话题名称和对应话题 ID 供选择
- **固定提醒**：输出中附带 API Key 获取提醒

### 排序与口径

- 话题列表默认按使用次数降序输出；用户指定排序时，可切换浏览量、参与人数或原始顺序
- 作品列表默认按播放数降序输出；用户指定排序时，可切换点赞、评论、分享或原始顺序
- 作者级字段（粉丝数、关注数、作品数等）在该数据源实测常为 0，默认不展示，也不作为账号规模的判断依据

## 一键安装

### 前置条件

- Python 3.8+（仅使用标准库，无需安装额外依赖）
- 红狐数据 API Key（前往 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) 注册获取）

### 安装步骤

1. 将技能文件夹放入你的 Skills 目录
2. 配置环境变量 `REDFOX_API_KEY`（配置细节详见 `references/core_workflow.md`）
3. 无需安装额外依赖，直接使用

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 关键词搜话题 | 「帮我搜一下 TikTok 上 cat 相关的话题」 | 输出关键词相关话题列表（默认按使用次数降序） |
| 查看话题作品 | 「查一下话题 ID 7551 下面的作品」 | 输出该话题作品列表（默认按播放数降序） |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |
| 继续翻页 | 「看下一页」 | 基于上一页游标继续输出下一页 |
| 查看原始数据 | 「输出原始返回」 | 输出原始数据内容 |

## 注意事项

1. **数据真实性**：所有数值均来自数据服务返回，如实展示，严禁估算或编造
2. **查询无果不替换**：空结果时如实说明并给出可选调整方向，不自动改查其他关键词或话题
3. **积分保护**：每次成功查询可能消耗积分；未经用户明确指定，不主动翻页或批量查询多个关键词
4. **鉴权**：首次使用需配置环境变量 `REDFOX_API_KEY`，API Key 获取与配置详见 `references/core_workflow.md`
5. **链接完整性**：输出中的链接保持完整可点击，不使用被终端截断的 URL
6. **搜完必追问**：话题列表输出后主动提示用户是否查看其中某个话题下的作品
