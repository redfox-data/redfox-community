# 获取TikTok指定话题作品数据 / tiktok-topic-aweme-list

---

## 简介

输入 TikTok 话题 ID，一键获取话题下的作品列表：播放、点赞、评论、分享等核心数据与作品链接完整呈现，默认按播放数降序排列，快速看清话题下哪些作品最火。

**核心价值**

- 🎯 **话题视角**：以话题为中心聚合作品数据，一眼看清话题热度分布
- 📊 **指标齐全**：播放、点赞、评论、分享等核心指标一表呈现
- 🔗 **链接直达**：作品链接完整可点击，一键跳转核对原文
- ↕️ **灵活排序**：支持按播放、点赞、评论、分享排序

**适用对象**

- 🧑‍💻 **TikTok 内容运营** — 追踪话题热度，及时把握内容风向
- 📣 **品牌方 / MCN** — 评估话题价值，发现表现亮眼的作品与创作者
- ✍️ **创作者** — 参考话题下高播放作品，优化选题与内容策略

---

## 功能特性

### 核心功能

- 🔍 **话题作品查询**：按话题 ID 查询该话题下的作品列表
- 📊 **核心数据展示**：播放、点赞、评论、分享等指标以 Markdown 表格呈现
- 🔗 **完整作品链接**：使用完整链接直达作品，方便逐一核对
- ↕️ **多维度排序**：默认按播放数降序，可切换点赞、评论、分享排序
- 📄 **分页浏览**：附带下一页游标信息，可按需继续查看

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 查询话题作品 | 「查一下话题 2525872 的作品，话题名 charlidamelio」 | 输出该话题作品列表（默认按播放数降序） |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |

| 查看原始数据 | 「输出原始返回」 | 输出原始数据内容 |
