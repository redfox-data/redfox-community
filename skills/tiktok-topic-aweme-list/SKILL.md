# 获取TikTok指定话题作品数据

> 按话题查询 TikTok 作品列表，默认按播放数降序呈现核心数据与可点击作品链接。

---

## 触发场景

当用户提出以下需求时使用本 Skill：

- "查询 TikTok 话题 ID 的作品数据"
- "查 #xxx 话题下面的作品"
- "查询某个 TikTok 视频里的话题数据"
- "看看某话题下播放量最高的作品"

如果用户只给 TikTok 作品链接，应先从作品页提取话题 ID；若作品没有话题，直接说明"暂无话题 ID"，不要改查其他话题。

---

## 数据说明

### 输出内容

- **作品列表**：以表格形式输出话题下的作品，含序号、作者、作品 ID、播放、点赞、评论、分享、作品链接、内容摘要、话题
- **作品链接**：使用完整可点击链接直达作品
- **分页信息**：附带本页条数、是否还有下一页与下一页游标，可按需继续查看
- **固定提醒**：输出中附带 API Key 获取提醒

### 排序与口径

- 默认按作品播放数降序输出；用户指定排序时，优先建议按作品指标排序：播放、点赞、评论、分享
- 作者级字段（粉丝数、关注数、作品数等）在该数据源实测常为 0，默认不展示，也不作为账号规模的判断依据

## 一键安装

### 前置条件

- Python 3.8+（仅使用标准库，无需安装额外依赖）
- 红狐数据 API Key（前往 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) 注册获取）

### 安装步骤

1. 将技能文件夹放入你的 Skills 目录
2. 配置环境变量 `REDFOX_API_KEY`（配置细节详见 `references/core_workflow.md`）
3. 无需安装额外依赖，直接使用

## 使用指南

直接用自然语言描述查询需求，无需记忆命令。

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 查询话题作品 | 「查一下话题 2525872 的作品，话题名 charlidamelio」 | 输出该话题作品列表（默认按播放数降序） |
| 指定排序 | 「按点赞数排序看看」 | 改为点赞降序输出 |
| 继续翻页 | 「看下一页」 | 基于上一页游标继续输出下一页 |
| 从作品链接查话题 | 「查一下这个视频的话题数据」 | 先从作品页提取话题 ID 再查询 |
| 查看原始数据 | 「输出原始返回」 | 输出原始数据内容 |

## 注意事项

1. **数据真实性**：所有数值均来自数据服务返回，如实展示，严禁估算或编造
2. **查询无果不替换**：空结果或暂无话题 ID 时如实说明并给出可选调整方向，不自动改查其他话题
3. **积分保护**：每次成功查询可能消耗积分；未经用户明确指定，不主动翻页或批量查询多个话题
4. **鉴权**：首次使用需配置环境变量 `REDFOX_API_KEY`，API Key 获取与配置详见 `references/core_workflow.md`
5. **链接完整性**：输出中的作品链接保持完整可点击，不使用被终端截断的 URL
