# X (Twitter) 订阅账号推文 / x-subscribe

---

## 简介

帮你盯紧关注的 X (Twitter) 名人账号，每天自动汇总他们昨天 9:00 到今天 9:00（近 24 小时）发了什么，不用再一个个手动刷动态。

**核心价值**
订阅 Twitter 名人账号（榜单推荐 / 指定账号 / 关注列表探索三种来源），每日早上 9:00 自动拉取订阅账号昨日 9:00 至今日 9:00（近 24 小时）发布的推文，按账号分组生成 HTML 日报推送。解决出海品牌评估 KOL 合作窗口、MCN 批量盯几十个账号动态、创作者追踪头部账号发帖节奏三大痛点。

**适用对象**

- 🌏 出海品牌 / 投放人员 — 订阅候选 KOL 后自动汇总昨日发声，评估合作窗口
- 📦 MCN / 商务经纪 — 批量订阅 + 单报告覆盖几十个名人账号动态
- ✍️ 内容创作者 / 研究者 — 追踪头部账号发帖节奏与爆款内容，时间线报告便于对标学习

---

## 功能特性

### 核心功能

- **三入口订阅**：榜单批量订阅（Top 10/20/50）、指定 @handle 订阅、关注列表探索后订阅
- **每日自动推送**：自动化任务内置账号 handle，每天 9:00 自动拉取近 24 小时（昨日 9:00 ~ 今日 9:00）推文，无需手动操作
- **时间窗口过滤翻页**：接口不支持按时间排序，Skill 内部按「昨日 9:00 ~ 今日 9:00」时间窗口智能 cursor 翻页过滤
- **HTML 日报**：X 平台风格（白底 + X 蓝），按账号分组展示推文时间线，支持导出 PDF / 高清图片
- **互动数据**：浏览 / 点赞 / 转发 / 回复 / 发布时间一览无余，转推与引用自动标识
- **AI 语义总结**：AI 读推文内容，归纳「今日主题」（分析推文在说什么，按实际条数）+ 每个账号的「今日主题/观点」
- **无更新折叠**：昨日无更新 / 近 7 天无更新账号自动折叠提示

## 重要数据说明

### 订阅与推送规则

| 规则 | 说明 |
| ---- | ---- |
| 推送时间 | 每日早上 9:00 自动执行 |
| 数据范围 | 拉取订阅账号**昨日 9:00 ~ 今日 9:00**（近 24 小时，本地时区）发布的推文 |
| 订阅上限 | 总上限 100 个账号；单个自动化任务最多 50 个 |
| 存储方式 | 账号 handle 直接内置于自动化命令，无本地文件存储 |

### 榜单订阅来源

- 榜单订阅固定查询**昨日**的热门账号榜（每日 9:00 更新前一天数据，最多回溯 7 天）
- 支持性别（全部/男/女）与 32 个行业分类筛选，作为批量订阅的推荐来源
