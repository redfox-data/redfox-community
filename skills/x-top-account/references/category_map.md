# 行业分类映射表与匹配规则

## 传参规则

- 接口 `category` 参数传**行业中文名**（如 `"萌宠动物"`），全部行业传 `"all"`
- 用户自然语言描述 → 按关键词模糊匹配到行业 → 传对应中文名
- 例：用户问"宠物" → 传 `"萌宠动物"`；未提及行业 → 传 `"all"`
- 无法识别时降级为 `all`（全部行业），并列出完整行业列表供用户选择
- skill 内部（文档、配置、输出）不暴露英文分类值

## 性别映射

| 用户说 | 传参 | 展示 |
|--------|------|------|
| 男、男性、男生、男榜 | `male` | 男 |
| 女、女性、女生、女榜 | `female` | 女 |
| 全部、不分性别、未提及 | `all` | 全部 |

## 匹配策略

- **长词优先**：所有关键词按长度降序扫描，先命中长者（如 "健康生活" 优先于 "健康"）
- **全文扫描**：关键词出现在用户文本任意位置即命中
- **显式优先**：`--category` 参数支持直接传行业中文名或匹配关键词，优先级高于文本解析
- **降级兜底**：无任何命中时传 `all`，并在对话中告知用户当前为全部行业榜单
