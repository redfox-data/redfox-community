# X (Twitter) 热门账号榜 / x-top-account

**中文** | [English](README.en.md)

---

## 简介

帮你快速发现 X (Twitter) 平台最具影响力的账号，掌握全球头部创作者格局。

**核心价值**
基于每日 X 平台 TOP200 影响力账号的粉丝、涨幅、跨平台数据，帮你解决对标账号、海外投放、竞品监控、行业洞察四大核心问题。

**适用对象**

- 🌏 出海内容创作者 — 了解同赛道头部账号表现，寻找对标和学习对象
- 🏢 品牌方/海外投放 — 高效筛选优质达人，评估跨平台合作价值
- 📦 MCN 机构/跨境运营 — 掌握竞品动态，制定运营策略
- 📊 行业分析师 — 获取数据洞察，生成分析报告

---

## 功能特性

### 核心功能

- **排名查询**：查询 X 平台每日影响力账号榜，每页 20 条、共 10 页 200 条，支持翻页浏览
- **筛选过滤**：支持性别（全部/男/女）与 32 个行业分类精准查询，支持模糊词匹配（如"宠物"自动映射萌宠动物）
- **影响力评分**：结合粉丝数、互动量、曝光数等加权综合评估，满分 100 分
- **HTML 报告生成**：生成 X 平台风格的可视化 HTML 文件，账号名可点击跳转 X 主页，支持一键导出 PDF / 高清图片
- **订阅推送**：支持设置每日定时自动推送，也可按性别 / 行业组合订阅

- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。
