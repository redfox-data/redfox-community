# X (Twitter) 企业家榜单

## 1. 简介

提供 X (Twitter) 企业家每日影响力排名、涨粉动态与推文话题分析。

**不止告诉你谁有影响力，还告诉你谁在涨粉、大佬们正在聊什么。**

**适用对象**：财经自媒体、投资人、分析师、出海品牌 PR / 市场团队、创业者与职场人。

---

## 2. 功能特性

- **企业家影响力榜**：排名、公司/职位、简介、国家/地区、粉丝总数、日涨幅、增长量与综合影响力
- **涨粉 TOP3**：查看单日新增粉丝最多的账号，分析各自最新原创推文，推测涨粉原因
- **大佬们在关注什么**：归纳榜内账号近期推文话题，附原文链接
- **翻页与报告**：每页 20 条，支持 HTML 报告及 PDF / 高清图片导出
- **双线订阅**：支持订阅每日榜单排名更新、和企业家x每日发布作品

## 4. 使用指南

### 基础使用

在 skill 根目录依次查询榜单、拉取推文、生成报告：

```bash
python scripts/fetch_rank.py --query "给我看最新的 Twitter 企业家榜"
python scripts/fetch_tweets.py --data entrepreneur_rank_data.json --days 30 --max 20
python scripts/generate_report.py --data entrepreneur_rank_data.json --tweets entrepreneur_tweets.json
```

**指定日期或翻页**（将 `YYYY-MM-DD` 替换为实际榜单日期）：

```bash
python scripts/fetch_rank.py --date YYYY-MM-DD --page 2
```

翻页后重新拉取本页推文并生成报告，不重复输出涨粉 TOP3。

### 查询方式

| 需求 | 示例 | 查询结果 |
| ---- | ---- | -------- |
| 看榜单 | 给我看最新的 Twitter 企业家榜 | 默认展示前 20 名、涨粉 TOP3 和话题总结 |
| 翻页 | 继续看第二页 | 查看同一期后续排名 |
| 下载报告 | 导出这期榜单 | 提供 HTML 报告 |

### 日期与订阅

榜单每日 **9:00** 更新前一天数据，最多回溯 **7 天**，9:00 前默认前日。指定日期不可用时说明实际采用日期。话题分析获取本页各用户最新发布的前 20 条推文，选取其中近 30 天的内容进行分析，单独标注时间范围。

| 订阅类型 | 推送内容 | 时间 |
| -------- | -------- | ---- |
| 榜单排名订阅 | 企业家榜最新排名与报告 | 每日 9:30 |
| 发帖日报订阅 | Top 20/50 昨日发帖关注要点 | 每日 9:00 |

确认订阅类型、时区与账号范围后创建任务。发帖日报复用 `twitter-subscribe`，最多 **100 个账号**；超量请联系 **redfoxdata@proton.me**。

### 输出格式

```text
💡 榜单说明：Twitter 企业家榜每日早上 9:00 更新前一日数据，与实时数据存在差异，最多回溯 7 天。
综合影响力：结合粉丝数、互动量、曝光数等加权综合评估，满分 100。
📊 {日期} Twitter 企业家榜
第 {当前页}/{总页数} 页，共 {总账号数} 个账号，本页展示 {条数} 条。

| 排名 | 账号名 | 关联公司/职位 | 简介 | 国家/地区 | 粉丝总数 | 粉丝日涨幅 | 粉丝增长量 | 综合影响力 |
|:---:|--------|--------|--------|:---:|:---:|:---:|:---:|:---:|
| {排名} | [{账号名}]({主页链接}) | {公司·职位} | {简介原文} | {国家/地区} | {粉丝数} | {日涨幅} | {增长量} | {评分} |

🚀 今日涨粉榜 TOP3（按单日新增粉丝数排序，统计范围：本页账号）
1. **{账号名}**（{公司·职位}）单日涨粉约 {增长量} ｜ 日涨幅 {日涨幅}
   最新 3 条原创推文：
   - {日期} · {推文摘要与分析} · [原文]({推文链接})
   涨粉原因推测：{结合这3条推文，分析可能吸引关注的因素}

💡 大佬们在关注什么（获取本页各用户最新发布的前 20 条推文，分析其中近 30 天的内容）
1. **{话题名}**
   {100~200字分析：讨论什么、谁在说、有哪些不同观点；关键论点附原文链接}

（以上为基于公开推文的 AI 分析与推测，仅供参考。）

⚡ 更多操作
• {HTML报告入口}，支持导出 PDF / 高清图片
• 是否继续查看第 {下一页} 页？

📬 订阅服务
1️⃣ 订阅企业家榜每日排名更新
2️⃣ 订阅 Top 20/50 发帖日报——每天 9:00 收到昨日发帖关注要点
3️⃣ 暂不需要
```

**内容要求**：

- 表格保留 9 列与原始排名，账号名可点击。公司/职位依据资料客观提炼，简介保留原文，不改写、不翻译，不作账号资格评判；长简介截断加 `…`，报告中保留全文。
- 粉丝数沿用榜单的 `w` / 亿格式，评分四舍五入取整，缺失信息用 `—`；报告与对话数据一致。
- 涨粉 TOP3 每个账号附最新 3 条原创推文链接及分析，以 1~2 句给出可能原因，明确为推测。
- 话题标题加粗，每个话题分析 100~200 字，论点附原文链接。推文或话题不足 3 条时如实说明，失败账号跳过，不虚构。

## 7. 常见问答

**Q: 报告在哪里？**
A: 默认保存到 `output/X企业家榜_{日期}_第{页码}页.html`，可用浏览器打开并导出。

**Q: 能查看全部上榜账号吗？**
A: 可以逐页浏览，每页 20 条，总页数与账号数以当期榜单为准。

**Q: 推文分析覆盖全部发帖吗？**
A: 本次分析使用各账号第一页中近 30 天的推文，并非全部历史发帖。
