# Facebook 评论分析 / facebook-comment

---

## 简介

只需粘贴一个 Facebook 帖子链接，即可获取评论区数据，并按积极 / 负面 / 需求 / 竞品四个维度做 AI 情感总结，快速看清一条帖子下的用户反馈与舆情全貌。

**核心价值**

- **一键获取评论**：粘贴帖子链接即可拉取评论区内容，无需手动翻找、逐条复制。
- **AI 舆情总结**：自动从积极、负面、用户需求、竞品对比四个维度归纳，快速把握整体口碑。
- **可视化留存**：分析结果可生成交互式报告，方便离线保存、分享与复盘。

**适用对象**

- 📊 **品牌方 / 运营人员** — 监测帖子评论舆情，及时发现负面反馈与用户诉求。
- 🎬 **内容创作者** — 了解受众真实反馈，为选题与内容优化提供依据。
- 🔍 **市场调研 / 竞品分析** — 从评论中捕捉竞品对比与用户偏好。
- 🤝 **MCN / 达人商务** — 评估合作内容的评论区口碑与互动质量。

---

## 功能特性

### 核心功能

- **评论获取**：粘贴帖子链接即可获取该帖评论区数据，包含评论人、评论内容、点赞数与发布时间。
- **分页浏览**：支持翻页，逐页查看大量评论。
- **AI 情感总结**：对评论做四维情感分析（积极 / 负面 / 需求 / 竞品），每条要点附代表评论关键词。
- **可视化报告**：生成交互式报告，可离线保存与分享；浏览多页后可合并为一份完整报告。

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图         | 示例话术                                       | 效果                             |
| ------------ | ---------------------------------------------- | -------------------------------- |
| 分析帖子评论 | 「分析一下这个帖子的评论：<帖子链接>」         | 获取第 1 页评论并输出 AI 总结    |
| 翻页看更多   | 「下一页」                                     | 加载下一页评论，按累计数据综合分析 |
| 生成报告     | 「生成 HTML 可视化报告」                       | 输出交互式报告，多页自动合并     |

### 输出示例

获取评论后，你将先看到当前页评论表格与 AI 总结（示意）：

```
📊 帖子「<帖子链接>」共获取 N 条评论（第 1 页）

| 评论人 | 评论内容             | 👍 点赞 | 时间        |
|-------|---------------------|:------:|------------|
| Amy   | 这个太实用了，收藏！  | 128    | 10-18 12:07 |

📈 评论总结分析（基于 N 条评论）
✅ 积极评价（62%）— 多数用户认可内容实用…
⚠️ 负面评价（8%）— 少数反馈加载较慢…
💡 用户需求（20%）— 希望增加中文说明…
🔍 竞品对比舆情（—）— 未提及竞品
```

## 重要数据说明

- 评论发布时间统一转为北京时间（UTC+8）展示；翻页依赖上一页返回的游标，游标为空表示没有更多数据。
- 情感占比为四类评论的比例，一条评论可能同时命中多个维度，四类总和可能超过 100%；总结为 AI 归纳，供参考。
