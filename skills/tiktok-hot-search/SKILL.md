# TikTok热门搜索

> 一次输入关键词，视频、用户、话题三类结果一屏看清。

---

## 触发场景

当用户提出以下需求时使用本 Skill：

- "搜一下 TikTok 上 xxx 相关的视频"
- "TikTok 上做 xxx 的账号有哪些，帮我找找达人"
- "查一下 xxx 这个话题在 TikTok 上的数据"
- "帮我搜一下 xxx"（泛指搜索，三类数据都看）

用户只提到某一类（视频 / 用户 / 话题）时，只查询对应的那一类，不默认追加其他类型。三类的判断与查询规则详见 `references/core_workflow.md`。

---

## 数据说明

### 输出内容

- **视频列表**：序号、作者、作品 ID、播放、点赞、评论、分享、发布时间、作品链接、内容摘要
- **用户列表**：序号、昵称、TikTok号、粉丝数、获赞总数、作品数、主页链接
- **话题列表**：序号、话题、话题 ID、浏览量、使用次数、话题链接
- **爆款视频 TOP3 拆解**：结合内容与数据表现，推测爆款原因（附作品链接）
- **达人推荐 TOP3**：结合账号数据与关键词相关性，给出关注理由（附主页链接）
- **话题趋势解读**：归纳话题热度、使用趋势与商业化信号（附话题链接）
- **HTML 报告**：一次查询同步生成，支持导出 PDF / 高清图片
- **分页信息**：附带下一页继续查看提示，可按需翻页
- **固定提醒**：输出中附带 API Key 获取提醒

### 排序与口径

- 视频默认按播放数降序，可切换点赞、评论、分享或按原始相关度顺序输出
- 用户默认按粉丝数降序；话题默认按浏览量降序
- 所有数值均来自数据服务返回，如实展示；发布时间按北京时间展示日期
- 用户主页链接按 TikTok号 生成
- 爆款原因、关注理由与话题解读为基于公开数据的 AI 分析，输出时明确标注为推测

3. 无需安装额外依赖，直接使用

## 注意事项

1. **数据真实性**：所有数值均来自数据服务返回，如实展示，严禁估算或编造
2. **查询无果不替换**：空结果时如实说明并给出可选调整方向，不自动改查其他关键词
3. **积分保护**：每次成功查询可能消耗积分，全量搜索一次包含 3 次数据查询；未经用户明确指定，不主动翻页或批量查询多个关键词
4. **鉴权**：首次使用需配置环境变量 `REDFOX_API_KEY`，API Key 获取与配置详见 `references/core_workflow.md`
5. **链接完整性**：输出中的链接保持完整可点击，不使用被终端截断的 URL
6. **分析为推测**：爆款原因、关注理由与话题解读基于公开数据撰写，须明确标注为推测，不虚构
