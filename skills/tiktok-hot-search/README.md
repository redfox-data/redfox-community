# TikTok热门搜索 / tiktok-hot-search

---

## 简介

输入关键词，一键同时获取 TikTok 上的热门视频、相关用户与相关话题：视频含播放、点赞、评论、分享与作品链接，用户含粉丝数、获赞总数与主页链接，话题含浏览量、使用次数与话题链接——一次搜索，三类数据一屏看清。

**核心价值**

- 🎯 **一次输入三类结果**：视频、用户、话题围绕同一关键词聚合输出，搜索视角完整
- 📊 **指标齐全**：视频播放 / 点赞 / 评论 / 分享 + 发布时间；用户粉丝数 / 获赞总数 / 作品数；话题浏览量 / 使用次数
- 🔗 **链接直达**：作品、用户主页、话题链接完整可点击，一键跳转核对
- ↕️ **灵活筛选**：视频支持排序与发布时间筛选，用户支持粉丝数与认证筛选

**适用对象**

- 🧑‍💻 **TikTok 内容运营** — 关键词选题调研，快速把握赛道内容风向
- 📣 **品牌方 / MCN** — 扫描竞品内容与优质达人，辅助出海投放决策
- ✍️ **创作者** — 找准话题与对标账号，优化选题与内容策略

---

## 功能特性

### 核心功能

- 🔍 **关键词全站搜索**：一次输入关键词，同时搜索视频、用户、话题
- 🎬 **视频搜索**：播放、点赞、评论、分享与发布时间，支持按播放、点赞、评论、分享排序与发布时间筛选（近 1 天 / 7 天 / 30 天 / 90 天 / 180 天）
- 👤 **用户搜索**：粉丝数、获赞总数、作品数，支持按粉丝数区间与认证状态筛选
- 🏷️ **话题搜索**：浏览量、使用次数与话题直达链接
- 🔗 **完整链接**：作品 / 主页 / 话题链接完整可点击，方便逐一核对
- 📄 **分页浏览**：附带下一页 offset 信息，可按需继续查看
- 🎯 **爆款视频 TOP3 拆解**：结合内容与数据表现，推测爆款原因
- 🚀 **达人推荐 TOP3**：结合账号数据与关键词相关性，给出关注理由
- 💡 **话题趋势解读**：归纳话题热度、使用趋势与商业化信号
- 📑 **HTML 报告**：一次查询同步生成，支持导出 PDF / 高清图片

## 使用指南

直接用自然语言描述搜索需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 搜索视频 | 「搜一下 TikTok 上 NVIDIA 的视频」 | 输出视频列表与爆款视频 TOP3 拆解（默认按播放数降序） |
| 找账号 / 达人 | 「TikTok 上做手冲咖啡的账号有哪些」 | 输出用户列表与达人推荐 TOP3（默认按粉丝数降序） |

| 排序与时间筛选 | 「按点赞排序，只看最近一周的」 | 视频按点赞降序 + 发布时间筛选 |
| 粉丝数筛选 | 「只看 10 万粉以上的账号」 | 用户按粉丝数区间筛选 |
| 继续翻页 | 「看下一页」 | 基于上一页提示的 offset 继续输出 |
| 导出报告 | 「导出报告」 | 提供 HTML 报告，支持导出 PDF / 高清图片 |
| 查看原始数据 | 「输出原始返回」 | 输出原始数据内容 |

## 重要数据说明

- 每次成功查询可能消耗积分，全量搜索一次包含 3 次数据查询，请按需查询
- 视频默认按播放数降序，用户默认按粉丝数降序，话题默认按浏览量降序
- 搜索结果较多时可按分页提示逐页查看
- 用户主页链接按 TikTok号 生成
- 爆款原因、关注理由与话题解读为基于公开数据的 AI 分析，明确标注为推测，仅供参考
