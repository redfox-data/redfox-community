# 小红书黑马爆文榜 / xiaohongshu-darkhorse

---

## 简介

一句分类或日期，就能捞出小红书上正在悄悄起量的黑马爆文：每条笔记附互动数据、发布时间与内容分析，并自动总结这批爆款的标题套路与内容特征，让你快速捕捉正在起量的内容方向。

**核心价值**

- 🏆 **发现黑马**：聚焦近期互动表现突出的黑马笔记，不限粉丝量级，比头部大 V 数据更能反映近期趋势
- 📊 **数据齐全**：标题、作者、粉丝数、发布时间、点赞、收藏、评论、分享、互动总数一表呈现
- 💡 **规律提炼**：自动拆解标题类型与内容主题分布，提炼可复用的写法亮点
- 🗂️ **分类与日期**：支持 25 个内容分类筛选、近 30 天任意一天榜单查询
- 🔔 **订阅与导出**：支持每日 19:30 自动推送，也可导出小红书风格完整页面（可存 PDF）

**适用对象**

- 📌 **小红书内容创作者** — 发现黑马选题，学习爆文写法，紧跟赛道风向
- 📈 **内容运营** — 黑马笔记是流量风向标，及时捕捉近期起量内容
- 📣 **MCN / 品牌方** — 挖掘潜力账号，评估合作对象的内容爆发力

---

## 功能特性

### 核心功能

- 📊 **分类筛选**：支持 25 个内容分类，输入分类名或关键词即可查询
- 📅 **日期查询**：支持查询近 30 天内任意一天的榜单，也可用「昨天」「三天前」等说法
- 🏆 **TOP50 榜单**：按互动总量从高到低排列，标注点赞、收藏、评论、分享数据
- 💡 **爆款规律分析**：自动拆解标题类型与内容主题分布，提炼可复用的写法亮点
- 🔔 **每日订阅推送**：订阅后每天 19:30 自动推送最新黑马爆文榜
- 📄 **文件包导出**：生成小红书风格的完整页面，支持导出 PDF，方便保存与分享

## 重要数据说明

- **榜单定位**：黑马爆文榜（按单日出榜），不是七日爆款笔记周榜；不限粉丝量级，重点呈现近期互动表现突出的内容
- **数据更新时间**：每天 17:30 开始更新昨日数据（17:30 前查询昨日数据尚未生成）
- **日期口径**：支持查询近 30 天内任意一天的榜单，统计窗口以指定日期为开始日期
- 每次成功查询可能消耗积分；未经明确指定，助手不会主动批量查询多个分类
