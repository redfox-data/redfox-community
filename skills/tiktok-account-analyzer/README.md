# TikTok账号深度分析 / tiktok-account-analyzer

---

## 简介

输入一个 TikTok 账号（主页链接 / @handle / secUserId / 昵称），一次输出账号基础信息、主页作品榜与喜欢作品透视：基础信息含粉丝数、获赞总数、地区与签名，作品含播放、点赞、评论、收藏、分享与作品链接——一个账号，三类数据一次看清。

**核心价值**

- 🎯 **一个输入三种定位**：主页链接、@handle、secUserId 可直接定位，昵称 / 关键词先展示候选账号确认
- 📊 **指标齐全**：粉丝 / 关注 / 获赞 / 作品数 + 地区 / 认证 / 签名；作品播放 / 点赞 / 评论 / 收藏 / 分享
- 📐 **六维量化诊断**：100 分制综合评分 + 四级评级，量级自适应基准，六类风险预警一次看清
- 🧭 **喜欢作品透视**：看清该账号平时喜欢什么内容、关注哪些作者圈层
- 🔗 **链接直达**：主页与作品链接完整可点击，一键跳转核对

**适用对象**

- 🤝 **品牌方 / MCN** — 合作前达人背调，评估账号数据表现与内容调性
- 🧑‍💻 **内容运营** — 拆解竞品账号的内容策略与爆款规律
- ✍️ **创作者** — 对标账号分析，找准自身定位与选题方向

---

## 功能特性

### 核心功能

- 🔍 **多方式定位账号**：主页链接、@handle、secUserId 直接定位；昵称 / 关键词搜索后展示候选账号供确认
- 👤 **账号基础信息**：昵称、TikTok号、粉丝数、关注数、获赞总数、作品数、地区、认证、签名与主页链接
- 📊 **主页作品榜**：播放、点赞、评论、收藏、分享与发布时间，按发布时间倒序
- 🧡 **喜欢作品透视**：该账号喜欢（点赞）的作品，含作者、播放、点赞与作品链接
- 🔗 **完整链接**：主页 / 作品链接完整可点击，方便逐一核对
- 📄 **分页浏览**：主页作品本地翻页零消耗，喜欢作品按游标翻页
- 📐 **六维量化诊断**：账号基础画像 / 内容生产力 / 互动健康度 / 内容质量 / 内容趋势 / 粉丝质量，100 分制评分 + 四级评级 + 僵尸粉 / 刷量 / 衰退 / 限流 / 断更 / 单条依赖六类风险预警，量级自适应基准，规则化离线计算不消耗积分
- 🎯 **爆款作品 TOP3 拆解**：结合内容与数据表现，推测爆款原因
- 💡 **喜欢偏好解读**：归纳该账号喜欢的内容类型与作者圈层
- 🔍 **账号诊断总结**：账号定位、内容策略、数据表现与商业化信号
- 📑 **HTML 报告**：一次查询同步生成，含六维量化诊断、爆款作品 TOP3 拆解与账号诊断总结，支持导出 PDF / 高清图片

## 密钥获取与安全说明

- 本技能需要使用环境变量：`REDFOX_API_KEY`。
- `REDFOX_API_KEY` 由 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) (`https://redfox.hk`)提供。
- 请前往 [红狐 hub](https://redfox.hk?source=github) 注册账号，获取 `REDFOX_API_KEY`。
- 配置设备环境变量 `REDFOX_API_KEY` 后使用本技能。
- 在提供密钥前，请先确认密钥来源、可用范围、有效期及是否支持重置/撤销。
- 禁止在代码、提示词、日志或输出文件中硬编码/明文暴露密钥。

## 使用指南

直接用自然语言描述分析需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 分析指定账号 | 「分析一下这个账号」+ 主页链接 / @handle / secUserId | 输出账号基础信息、主页作品榜与喜欢作品透视 |
| 达人背调 | 「帮我背调一下 @tomcurtainofficial」 | 基础信息 + 主页作品 + 喜欢作品一次输出，附六维量化诊断与诊断总结 |
| 按昵称找账号 | 「分析一下 Tom Curtain 这个账号」 | 先展示候选账号供确认，选定后继续分析 |
| 量化诊断 | 「给这个账号打个分」「评估合作价值」 | 输出六维量化诊断：综合评分、维度明细与风险预警 |
| 只看主页作品 | 「看看这个账号最近发了什么」 | 输出主页作品榜与爆款作品 TOP3 拆解 |
| 只看喜欢作品 | 「看看这个账号喜欢什么内容」 | 输出喜欢作品透视与喜欢偏好解读 |
| 继续翻页 | 「看下一页」 | 基于上一页提示继续输出下一页 |
| 导出报告 | 「导出报告」 | 提供 HTML 报告，支持导出 PDF / 高清图片 |
| 查看原始数据 | 「输出原始返回」 | 输出原始数据内容 |

## 重要数据说明

- 每次成功查询可能消耗积分，全量分析一次最多包含 3 次数据查询（搜索定位 + 主页作品 + 喜欢作品），请按需查询
- 六维量化诊断与 HTML 报告为本地离线计算 / 生成，不消耗积分
- 主页作品与喜欢作品均按发布时间倒序展示，爆款拆解按播放数降序取 TOP3
- 昵称 / 关键词存在重名情况，请先确认候选账号后再分析
- 喜欢列表为私密的账号可能查不到喜欢作品，此时如实说明
- HTML 报告中的爆款拆解与账号诊断总结与对话输出一致，均为基于公开数据的 AI 分析，明确标注为推测，仅供参考
- 六维量化诊断的评分基准为 TikTok 初始校准值，随样本积累持续微调
