# TikTok 账号六维量化诊断 - 评分规则

> 本文件定义 tiktok-account-analyzer 技能「六维量化诊断」板块的评分规则。
> 评分模型移植自 douyin-account-diagnosis 技能（六维度 + 量级自适应 + 风险预警），
> 字段口径已按 TikTok 数据适配。评分由 `scripts/tiktok_diagnosis.py` 离线计算，
> 读取 `--save-json` 落盘的查询结果，不发起接口调用、不消耗积分。
>
> **评分设计原则：基准随账号量级自适应。** TikTok 互动指标与粉丝体量强负相关，
> 因此所有互动类指标按量级分档设定基准，不使用一套绝对阈值同时评判尾部与超头部账号。
>
> **第二原则：账号不为「数据可得性」买单，也不因「数据不足」白拿分。**
> 凡不可靠或不可计算的子项一律不计入分母（不奖不罚），报告标注 `[有效满分X，满分Y]`；
> 但「账号确实没有作品数据」是负面信号，相关子项按最低档计分（0 分）、不得剔除。

## 数据口径（TikTok 字段映射）

评分输入来自 `output/tiktok_account_latest.json`：

| 项目 | 字段 | 说明 |
|------|------|------|
| 粉丝数 | profile.fans（fansCount） | 全部粉丝类指标的分母 |
| 获赞总数 | profile.liked（likedTotal） | 粉丝获赞比 / 人均获赞 / 获赞背离 |
| 作品数 | profile.works（workCount） | 作品总量 / 人均获赞分母 |
| 头像 | profile.avatar（avatarImage） | 账号基础画像 |
| 签名 | profile.signature（userSignature） | 账号基础画像 |
| 地区 | profile.area（userArea） | 账号基础画像（TikTok 仅此 1 个字段） |
| TikTok号 | profile.handle（userHandle） | 账号基础画像 |
| 作品列表 | works.items | 每条含 publishTime（秒级时间戳）、播放 views、点赞 likes、评论 comments、收藏 favorites、分享 shares |

> 抖音模型使用 `interactiveCount = 赞+评+转`，TikTok 数据多一个「收藏」维度且
> 「播放」是大头，故口径调整为：**黏性指标用点赞**（均点赞/粉丝），
> **声量指标用播放**（均播放、趋势、集中度）。收藏仅展示不计分（v1）。

## 样本充分性（与抖音模型一致）

| 子项 | 退化原因 | 门槛 |
|------|----------|------|
| 中位/均值偏离 | n=2 时中位数恒等于均值，偏离度恒为 0 | n ≥ 3 |
| 爆款集中度 | 集中度 = max/avg 恒 ∈ [1, n]，n 过小时必然满分 | n ≥ 5 |
| 互动稳定性 CV | n<5 时离散度无统计意义 | n ≥ 5 |
| 发布频率 | 样本窗口过短时只是最后两条的间隔倒数 | n ≥ 5 |
| 近期趋势 / 衰退预警 | 快照下越新的作品累计播放越少，会把「最近发布」读成「衰退」 | 成熟作品(≥3天) ≥ 4 条 |

**不可计算 vs 数据不足 vs 无内容（三者的处理完全不同）**

| 情形 | 处理 |
|------|------|
| 样本不足（子项数学退化） | 不计入分母（不奖不罚） |
| 比值为 0/0（互动全 0、粉丝数为 0 等） | 不计入分母（不奖不罚） |
| 字段缺失（作品缺 publishTime） | 不计入分母（不奖不罚） |
| 无作品数据（works 为空） | 依赖作品的子项按最低档计 0 分，**不剔除分母**（账号没有内容可评属负面信号） |

被剔除的子项在报告中渲染为 `(不计入)`，维度标题标注有效满分；样本 < 5 条时输出
`ⓘ 数据置信度` 提示。⚠️ 实现陷阱：`_cv()` 在均值为 0 时返回 0.0，与「真的完全稳定」
同值，会误判互动全零账号为「稳定输出满分」，调用前必须先拦截「均值 ≤ 0」。

## 维度1：账号基础画像（8 分，权重 10%）

| 指标 | 满分 | 评分规则 |
|------|------|----------|
| 头像 | 2 | avatar 非空 = 2；空 = 0 |
| 签名 | 3 | ≥15 字 = 3；>0 且 <15 字 = 1；空 = 0 |
| 地区 | 2 | area 非空 = 2；空 = 0 |
| TikTok号 | 1 | handle 非空 = 1；空 = 0 |

> TikTok 仅有 `userArea` 一个地域字段（抖音为 province+ipLocation 两个），
> 故地域子项由「完整度 2 选 1」简化为「有/无」2 分制，卷面仍为 8 分。

## 维度2：内容生产力（15 分，权重 15%）

### 作品总量（5 分）—— 门槛量级自适应

| 判定 | 得分 | 说明 |
|------|------|------|
| ≥ 异常高产线 | 4 | 极高产（需警惕刷量） |
| ≥ 高产线 | 5 | 高产 |
| ≥ 正常线 | 4 | 正常 |
| < 正常线 | 2 | 偏少 |

### 人均获赞（5 分）—— 门槛量级自适应

| 判定 | 得分 | 说明 |
|------|------|------|
| ≥ 高效线 | 5 | 高效 |
| ≥ 良好线 | 4 | 良好 |
| ≥ 正常线 | 3 | 正常 |
| < 正常线 | 1 | 低效 |

> 作品数为 0 且无作品列表 → 按最低档计 0 分（不剔除）。

### 发布频率（5 分）

频率 = 返回作品数 /（最新 - 最早 publishTime 的天数）

| 范围 | 得分 | 说明 |
|------|------|------|
| < 0.5 条/日 | 2 | 低频 |
| 0.5 - 2 条/日 | 5 | 正常 |
| 2 - 3 条/日 | 4 | 高频 |
| > 3 条/日 | 3 | 极高频 |

> 返回作品数 < 5 时不计入分母（样本窗口无代表性）。

## 维度3：互动健康度（30 分，权重 30%）

### 粉丝获赞比（10 分）

比值 = 获赞总数 / 粉丝数

| 范围 | 得分 | 说明 |
|------|------|------|
| ≥ 25 | 10 | 优质（长尾效应强） |
| 15 - 24.99 | 9 | 良好 |
| 8 - 14.99 | 8 | 正常 |
| 3 - 7.99 | 6 | 一般 |
| 1 - 2.99 | 3 | 偏低 |
| < 1 | 1 | 极低 |

> 粉丝数为 0 → 0/0 不可计算，不计入分母。

### 粉丝互动率（10 分）—— 量级自适应

互动率 = 近期作品均点赞 / 粉丝数 × 100%，查「粉丝互动率基准」表：

| 条件 | 得分 | 说明 |
|------|------|------|
| ≥ 本量级优秀线 | 10 | 优秀 |
| ≥ 本量级良好线 | 7 | 良好 |
| ≥ 本量级偏低线 | 4 | 偏低 |
| < 本量级偏低线 | 1 | 极低 |

> 无作品数据 → 按最低档计 0/10；粉丝数为 0 → 不计入分母。

### 互动结构比（5 分）

以点赞为 100，计算评论占比（Σ评论/Σ点赞）与分享占比（Σ分享/Σ点赞）：

| 条件 | 得分 | 说明 |
|------|------|------|
| 评论占比 ≥ 4% 且 分享占比 ≥ 4% | 5 | 健康 |
| 评论占比 ≥ 3% 且 分享占比 ≥ 3% | 4 | 较健康 |
| 评论占比 ≥ 2% 或 分享占比 ≥ 2% | 3 | 一般 |
| 均低于 2% | 2 | 互动单一 |

> 无作品数据 → 按最低档计 0/5；点赞总数为 0 → 0/0 不计入分母。

### 作品均播放（5 分）—— 绝对声量（量级自适应）

均播放 = mean(works.views)，按「作品均播放基准」表分档：现象级 5 / 强传播 4 /
中等 3 / 偏弱 2 / 微弱 1。均播放为 0 属可计算事实，按微弱 1 分（不剔除）。

## 维度4：内容质量（20 分，权重 20%）

### 爆款率（6 分）—— 爆款线量级自适应

爆款定义：单作品点赞 > 粉丝数 × 本量级爆款线。爆款率 = 爆款作品数 / 作品总数：

| 范围 | 得分 | 说明 |
|------|------|------|
| > 10% | 6 | 优秀 |
| 5 - 10% | 4 | 良好 |
| > 0% 且 < 5% | 3 | 偏低 |
| 0% | 1 | 无爆款 |

### 中位/均值偏离（4 分）

按点赞计算：偏离度 = |中位数 - 均值| / 均值

| 偏离度 | 得分 | 说明 |
|--------|------|------|
| < 0.2 | 4 | 分布均匀 |
| 0.2 - 0.5 | 3 | 轻度偏离 |
| ≥ 0.5 | 1 | 严重偏离（靠爆款拉动） |

> n < 3 或点赞均值为 0 → 不计入分母。

### 互动稳定性（5 分）

按播放计算变异系数 CV = 标准差 / 均值

| CV 范围 | 得分 | 说明 |
|---------|------|------|
| < 0.5 | 5 | 稳定输出 |
| 0.5 - 1.0 | 3 | 波动一般 |
| ≥ 1.0 | 1 | 严重依赖爆款 |

> n < 5 或播放均值为 0 → 不计入分母（均值 ≤ 0 必须先拦截）。

### 零互动占比（5 分）

零互动作品定义：点赞 < 10。占比 = 零互动作品数 / 作品总数：

| 范围 | 得分 | 说明 |
|------|------|------|
| < 5% | 5 | 质量稳定 |
| 5 - 20% | 3 | 部分低质 |
| ≥ 20% | 1 | 大量低质/限流 |

## 维度5：内容趋势（15 分，权重 15%）

### 近期趋势（5 分）

只比较「已发布满 3 天」的成熟作品，按播放取最早 1/3 与最近 1/3 的均播放。
变化率 = (近期均播放 - 早期均播放) / 早期均播放：

| 变化率 | 得分 | 说明 |
|------|------|------|
| > +20% | 5 | 增长期 |
| -20% ~ +20% | 4 | 平稳期 |
| -50% ~ -20% | 2 | 衰退期 |
| < -50% | 1 | 严重衰退 |

> 成熟作品 < 4 条或早期均播放为 0 → 不计入分母。
> 快照偏差说明：接口返回的是「截至采集时刻的累计播放」，越新的作品累计越少，
> 直接比较会把「最近发布」读成「衰退」，故必须剔除未满 3 天的作品。

### 爆款集中度（5 分）

集中度 = max(播放) / avg(播放)

| 集中度 | 得分 | 说明 |
|--------|------|------|
| < 3 倍 | 5 | 均匀分布 |
| 3 - 5 倍 | 4 | 较为均匀 |
| 5 - 10 倍 | 2 | 依赖爆款 |
| ≥ 10 倍 | 1 | 严重依赖单条 |

> n < 5 或均播放为 0 → 不计入分母。

### 最新活跃度（5 分）

最新活跃天数 = 参考时间 - 最新作品 publishTime（参考时间取 meta.generatedAt，
缺失或滞后时回退当前时间；天数恒取 max(0, …)）：

| 天数 | 得分 | 说明 |
|------|------|------|
| ≤ 3 天 | 5 | 活跃 |
| 4 - 7 天 | 4 | 正常 |
| 8 - 14 天 | 2 | 偏沉默 |
| > 14 天 | 1 | 已断更 |

> 无作品数据 → 按最低档计 0/5。

## 维度6：粉丝质量（10 分，权重 10%）

### 粉丝规模（4 分）

由量级直接派生（与「账号量级分层」同源）：S → 4 / A → 3 / B → 2 / C → 1。

### 粉丝互动比（3 分）—— 量级自适应

与「粉丝互动率」同源，查量级基准表的良好线 / 偏低线：

| 条件 | 得分 | 说明 |
|------|------|------|
| ≥ 本量级良好线 | 3 | 粉丝活跃 |
| ≥ 本量级偏低线 | 2 | 粉丝一般 |
| < 本量级偏低线 | 1 | 粉丝不活跃 |

> 无作品数据 → 按最低档计 0/3；粉丝数为 0 → 不计入分母。

### 获赞/粉丝背离（3 分）

| 比值 | 得分 | 说明 |
|------|------|------|
| ≤ 50 | 3 | 正常 |
| 50 - 100 | 2 | 偏高 |
| > 100 | 1 | 异常高（疑似刷赞/搬运） |

## 有效满分与综合评分

```
维度归一化分 = 维度得分 / 维度有效满分 × 100
综合评分     = Σ(维度归一化分 × 权重)，四舍五入取整（ROUND_HALF_UP）
```

权重：账号基础画像 10% / 内容生产力 15% / 互动健康度 30% / 内容质量 20% /
内容趋势 15% / 粉丝质量 10%。

> Python 内置 `round()` 为银行家舍入（四舍六入五成双），实现须显式用
> ROUND_HALF_UP。样本 < 5 条时报告输出 `ⓘ 数据置信度` 提示；作品数为 0 时
> 改输出 `ⓘ 无近期作品数据` 提示。

## 风险预警（阈值与评分基准同源）

| 预警类型 | 触发条件 | 风险等级 |
|----------|----------|----------|
| 🚨 僵尸粉预警 | 粉丝互动率 < 本量级偏低线 且粉丝数 > 5 万 | 高危 |
| 🚨 刷量预警 | 获赞/粉丝比 > 100 且近期互动骤降（与衰退共用成熟样本） | 高危 |
| ⚠️ 衰退预警 | 近期均播放 < 早期的 50%（仅比较满 3 天作品，且需 ≥ 4 条） | 中危 |
| ⚠️ 限流预警 | 零互动占比 > 30% | 中危 |
| ⚠️ 断更预警 | 最新作品距参考时间 > 14 天 | 中危 |
| ℹ️ 单条依赖预警 | 最大爆款播放 > 均值的 10 倍 | 低危 |

> 无预警时输出「无」。成熟样本不足时不触发衰退/刷量预警，不拿未成熟作品给反向结论。
