# TikTok账号深度分析

> 输入一个 TikTok 账号，基础信息、主页作品、喜欢作品三类数据一次看清。

---

## 触发场景

当用户提出以下需求时使用本 Skill：

- "帮我分析一下这个 TikTok 账号"（附主页链接 / @handle / secUserId）
- "帮我背调一下这个达人，看看值不值得合作"
- "拆解一下竞品账号的内容策略"
- "看看这个博主最近发了什么、数据怎么样"
- "搜一下 xxx（昵称/关键词），帮我找找对应账号并分析"

账号定位规则（昵称 / 关键词需搜索确认、主页链接 / handle / secUserId 可直接定位）与三类数据的查询规则详见 `references/core_workflow.md`。

---

## 数据说明

### 输出内容

- **账号基础信息**：昵称、TikTok号、粉丝数、关注数、获赞总数、作品数、地区、认证、签名与主页链接
- **主页作品榜**：序号、发布时间、作品、播放、点赞、评论、收藏、分享与作品链接
- **喜欢作品透视**：该账号喜欢（点赞）的作品，含发布时间、作品、作者、播放、点赞与作品链接
- **六维量化诊断**：100 分制综合评分 + 四级评级，覆盖账号基础画像 / 内容生产力 / 互动健康度 / 内容质量 / 内容趋势 / 粉丝质量六维度，量级自适应基准，附六类风险预警（僵尸粉 / 刷量 / 衰退 / 限流 / 断更 / 单条依赖）
- **爆款作品 TOP3 拆解**：结合内容与数据表现，推测爆款原因（附作品链接）
- **喜欢偏好解读**：归纳该账号喜欢的内容类型与作者圈层（明确为推测）
- **账号诊断总结**：账号定位、内容策略、数据表现与商业化信号（100~200 字分析）
- **HTML 报告**：一次查询同步生成，含六维量化诊断、爆款作品 TOP3 拆解与账号诊断总结，支持导出 PDF / 高清图片
- **分页信息**：主页作品与喜欢作品均支持翻页查看
- **固定提醒**：输出中附带 API Key 获取提醒

### 排序与口径

- 主页作品与喜欢作品均按发布时间倒序；爆款拆解按播放数降序取 TOP3
- 所有数值均来自数据服务返回，如实展示；发布时间按北京时间展示日期
- 主页链接按 TikTok号 生成；作品链接使用接口返回的完整链接
- 喜欢列表为私密的账号可能查不到喜欢作品，此时如实说明
- 爆款原因、喜欢偏好与账号诊断为基于公开数据的 AI 分析，输出时明确标注为推测
- 六维量化诊断由规则离线计算（不消耗积分），评分规则详见 `references/diagnosis_rules.md`；评分基准为 TikTok 初始校准值，随样本积累持续微调

## 一键安装

### 前置条件

- Python 3.8+（仅使用标准库，无需安装额外依赖）
- 红狐数据 API Key（前往 [红狐 hub](https://redfox.hk/settings/api-keys?source=github) 注册获取）

### 安装步骤

1. 将技能文件夹放入你的 Skills 目录
2. 配置环境变量 `REDFOX_API_KEY`（配置细节详见 `references/core_workflow.md`）
3. 无需安装额外依赖，直接使用

## 注意事项

1. **数据真实性**：所有数值均来自数据服务返回，如实展示，严禁估算或编造
2. **账号定位准确**：昵称 / 关键词存在重名情况，须先展示候选账号由用户确认后再分析；主页链接 / handle / secUserId 可直接定位
3. **积分保护**：每次成功查询可能消耗积分，全量分析一次最多包含 3 次数据查询（搜索定位 + 主页作品 + 喜欢作品）；六维量化诊断与 HTML 报告为本地离线计算，不消耗积分；未经用户明确指定，不主动翻页或批量查询多个账号
4. **鉴权**：首次使用需配置环境变量 `REDFOX_API_KEY`，API Key 获取与配置详见 `references/core_workflow.md`
5. **链接完整性**：输出中的链接保持完整可点击，不使用被终端截断的 URL
6. **分析为推测**：爆款原因、喜欢偏好与账号诊断基于公开数据撰写，须明确标注为推测，不虚构
